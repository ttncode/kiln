# kiln end to end: real sessions, a simulated user

> The owner asked for tests "as a real kiln user". `evals/e2e/` runs them (D196).

**How.** Each scenario copies `evals/e2e/project` (tasktrack: a small dependency-free Node app with
a latent dashboard crash, SHA-1 password hashing and a customer order history), commits it with a
bare `origin`, and runs real Claude Code sessions with kiln loaded from a checkout
(`--plugin-dir`, project settings only, permissions bypassed in the throwaway copy — kiln's own
hooks still run): first `/kiln:kiln init`, then the ticket. A simulated user — a separate model
that sees only the assistant's last message and a persona — answers every question until the work
is finished. The checks read kiln's own records and the repository, never what the assistant said.

| scenario | ticket |
|---|---|
| bugfix-dashboard | `--auto` The dashboard crashes whenever any project is on track. Fix it. |
| feature-user-search | `--auto` Add GET /api/users/search for signed-in staff; customers must not use it. |
| spike-password-hashing | Is the way we hash passwords safe? (no code change) |
| feature-archive-orders | `--auto` Customers archive an old order out of their history; nothing deleted. |

## What the rounds found

1. **A plan in the wrong template, approved without Risk flags** (round 1). The agent followed
   the copied planning skill's own template; `kiln practices --stage plan` had run before
   plan.md existed; the gate did not look. → one template, the plan gate requires Risk flags,
   and PLAN's practices wait for the plan's header (D190).
2. **The `lenses:` line wrapped at 80 columns** (round 1) and **ended with a full stop** (round 3):
   the review gate refused a correct account twice over. → read as a paragraph (D189) and with
   ordinary punctuation (D195).
3. **A ratchet that asked about kiln's own `.gitignore`** (smoke). → the earlier path's own
   changes only, and init now says its setup belongs in the repository (D194).
4. **The spike persona took the recommended ratchet** — a harness defect, fixed in the persona.
5. **Cost accounting.** A resumed session reports its running total on every result; summing
   them reported $81 for a $7 run. The harness takes the highest.
