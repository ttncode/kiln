# Code of conduct

## The standard

Be respectful, assume good faith, and keep disagreement about the work.

This project's normal mode is disagreement with a number attached: a decision is cited, a
measurement is offered, and the previous answer is superseded in public. That is welcome and
it is not incivility. What is not welcome:

- personal attacks, insults, or demeaning comments;
- harassment, public or private;
- sexualised language or imagery, and unwelcome advances;
- publishing anyone's private information without their permission;
- sustained disruption of discussion, issues, or reviews.

## Scope

Issues, pull requests, discussions, commit messages, and any space where someone is
representing this project.

## Enforcement

Report a problem to the maintainer, [@ttncode](https://github.com/ttncode), using the contact
details on that profile. For harassment that GitHub itself should see, use
[GitHub's report-abuse form](https://github.com/contact/report-abuse).

Reports are handled privately. Depending on severity the maintainer will respond with a
correction, a warning, a temporary block, or a permanent ban from the project's spaces. The
maintainer is one person, so an acknowledgement may take a few days; the response will say
what was decided and why.
